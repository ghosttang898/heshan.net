# AGENTS.md

## Project Rules

- Keep implementations simple and readable
- Authentication already exists and uses JWT with Spring Security
- Preserve Controller / Service / Repository layering
- Admin APIs must enforce ADMIN permissions on the backend, not just frontend routes
- Preserve existing public-site features and Chinese/Heshan community wording
- Update related API documentation when changing APIs
- Do not overengineer the architecture
- Prefer clear folder structure and minimal dependencies
- Backend uses Java 17, Spring Boot, and Maven
- Frontend uses React, Vite, and React Router
- Documentation belongs in `docs/`
