## 范围与真实状态

本项目按小型地方怀旧社区推进，不再以基础设施扩展作为上线前置条件。
本轮仅检查本地代码、Git 状态及已有验收记录；未连接 VPS、未运行新测试、
未修改数据库/权限/DNS、未提交推送或部署。以下 PASS 是此前实际验收成果，
不是本轮重新执行的测试。以最新所有者报告为准，不沿用旧文档中的过期
“恢复/持久化未测试”结论。

已完成并可保留使用：

- 注册、登录、退出、重新登录；注册角色固定 USER、JWT 与后端权限保护。
- 聊天发帖、列表、详情、评论；寻人发布、昵称/地点筛选及回复。
- 网站头、作者显示、注册页网站头、列表/评论 Loading、隐私说明。
- USER/ADMIN/SUPER_ADMIN 与一次性创始人初始化、角色变更审计。
  后端隔离权限测试通过，但真实管理员浏览器完整操作仍待收尾。
- IP 属地展示及未知回退；公开接口不返回完整 IP。公网城市准确度不作为上线门槛。
- 现有 Analytics 配置保留，Staging 不加载；不新增统计平台/API。
- Staging 的 HTTPS/API/SPA、已覆盖桌面/手机视口通过。
- PostgreSQL/Flyway/Hibernate、独立恢复和 Backend/DB 重启持久化通过，
  三容器健康，无 OOM/异常自动重启；现有 Volume、备份及报告全部保留。

已完成但未部署的业务修复：年份单值/区间交集搜索。
改动是 FindPeoplePage.jsx、FindPersonFilters.jsx、yearSearch.js 与测试；
此前本地 18 项前端测试、生产构建和桌面/手机验证通过，Staging 未更新。
已部署版本为 2e176e0，Git HEAD 也是 2e176e0；后续脚本/文档及年份修复仍在工作区，
不能误把本地文件存在视为 GitHub 已同步或服务器已部署。

本轮代码检查发现：AuthService、PostService、CommentService 对输入长度的
显式校验不足，相关 Controller 未使用 @Valid。过长输入可能转为数据库或编码错误，
部分帖子必填输入也缺少清晰后端拒绝逻辑。应做窄范围验证及 400 错误提示，不重构架构。
匿名评论目前是前后端共同支持的既有功能，不是自动认定的权限漏洞；上线前确认
是否保留，若要求必须登录再做对应的小改动，不能擅自删除现有行为。

只使用现有 VPS：React 静态文件 + Nginx + 已有 Spring Boot + 已有 PostgreSQL。
不新增 Cloudflare Pages、存储服务或其他常驻组件；保留已实现 Analytics，不修改
Cloudflare 配置。若需正式逻辑库，可在现有 PostgreSQL 服务中按批准方案隔离，

本期不继续开发：rclone/B2 集成、自动异地同步、新恢复自动化框架、新复杂部署
控制器、高并发优化、微服务/集群等与当前用户规模不相称的工作。已有脚本、
权限体系、备份、测试环境和稳定功能均不删除。已创建但未接入的 B2 凭据不使用、
不上传 VPS、不续建云资源；不自动撤销凭据或更改云端配置。

下一轮应先批准最小业务收尾（年份修复、输入边界及验收），而不是直接批准上线。
